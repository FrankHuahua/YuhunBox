# 御魂匣（YuhunBox）

一个面向《阴阳师》玩家的原生 iOS 御魂与队伍管理原型。项目使用 SwiftUI 编写，不依赖第三方库，所有数据默认只保存在设备本地。

## 0.2.0 已实现

- 沉浸式首页：深色全屏信息流、顶部“推荐 / 工具 / 最近”频道和自定义五栏底部导航。
- 快捷创建：底部中央入口可直接录入御魂、截图识别、新建队伍、扫码导入、打开配装模拟或速度轴。
- 配装模拟：按五种养成方向从本地库存自动选择六件套，可限定只使用已锁定御魂。
- 速度轴检查：按目标速度生成行动顺序，提示同速冲突和未填写速度的式神。
- 强化清单：集中查看各养成方向下 B 级以上、尚未 +15 的高潜胚子。
- 备份恢复：把御魂、队伍和偏好设置导出为 JSON 文件，并可从“文件”恢复。
- 全新图标：以雪御前的银白、冰蓝与绯红视觉特征创作原创 Q 版图标。

- 御魂库存：录入套装、位置、等级、主属性与副属性，支持搜索、筛选、编辑和删除。
- 截图识别：从相册选择御魂截图，使用 Apple Vision 在设备上识别文字，确认后入库。
- 强化建议：按一速、暴击输出、爆伤输出、命中控制、生存五种方向评分，给出强化到 `+3/+6/+9/+12/+15` 或整理建议，并从库存自动生成六件套候选。
- 账号方向：统计速度胚子、双暴胚子、命中胚子和六号位关键主属性，提示当前库存短板。
- 队伍预设：记录场景、式神、职责、御魂方案、速度目标和官方阵容码。
- 一键分享与扫码：生成 `YHX1` 格式的完整预设码，可复制、系统分享、生成二维码并通过相机扫码导入。
- 示例数据：首次启动自动生成一组可操作数据；可在“设置”里清除。

## 运行

1. 在装有 Xcode 15 或更高版本的 Mac 上打开 `YuhunBox.xcodeproj`。
2. 在 Signing & Capabilities 中选择你自己的 Team，并按需修改 Bundle Identifier。
3. 选择 iOS 16+ 模拟器或真机运行。二维码相机扫描需要真机；模拟器可粘贴阵容码。

需要生成 IPA 或通过 TestFlight 安装时，请继续阅读 [BUILDING.md](BUILDING.md)。项目已包含无签名 IPA 的 macOS/GitHub Actions 构建流程，以及 Development/Ad Hoc 的签名导出脚本。

项目同时附带 `project.yml`。如果你使用 [XcodeGen](https://github.com/yonaskolb/XcodeGen)，可在项目目录运行 `xcodegen generate` 重建工程文件。

## 关于游戏数据

第一版没有调用、抓取或逆向任何游戏接口。官方阵容码会作为原始文本随预设保存；本应用的 `YHX1` 码包含完整预设数据，可在本应用间互通。若后续获得官方公开格式或授权接口，可以在 `PresetCodeCodec` 旁新增适配器。

本项目是非官方玩家工具，不包含直接提取的游戏美术资源，与游戏厂商无隶属或背书关系。

原创图标的 1024px 成品位于资源目录，源图保留在 `Design/AppIcon-source.png`，上一版图标备份为 `Design/AppIcon-v1.png`。
